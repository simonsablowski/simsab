simsab
======

This is the personal website of [Simon Sablowski](https://simsab.net).

It is a static site without build step or dependencies: open `index.html` in a browser, or serve the directory with any web server, for example:

    python -m http.server

Structure:

- `index.html`: all content, including the legal notice and privacy policy
- `assets/css/main.css`: styles
- `assets/js/main.js`: navigation (smooth scrolling to `#focus`, `#services`, … and switching to `#legal-notice` and `#privacy-policy`)
- `assets/fonts`: self-hosted Alegreya and Nunito (SIL Open Font License)
- `assets/images`: portrait, illustrations, client logos, favicon and social card
